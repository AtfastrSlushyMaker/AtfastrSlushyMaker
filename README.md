## 🚀 Featured projects

### ☁️ Cloud & infrastructure

**[OpenStack & Kubernetes automation](https://github.com/AtfastrSlushyMaker/ansible-openstack-k8s)**
Ansible + Heat playbooks that provision Kubernetes on OpenStack, with KServe and Prometheus/Grafana monitoring.
<br /><sub>OpenStack · Ansible · Heat · Kubernetes · Prometheus · Grafana</sub>

**[MEMO](https://github.com/AtfastrSlushyMaker/memo)**
Multi-tenant workplace operations platform with real-time messaging and a [grounded AI assistant](https://github.com/AtfastrSlushyMaker/memo-agent), deployed on Azure AKS.
<br /><sub>Angular · Spring Boot · PostgreSQL · FastAPI · Azure AKS</sub>

### 🌍 Real-time & AI

**[AtlasMesh](https://github.com/AtfastrSlushyMaker/AtlasMesh)** · [Live demo](https://atlasmesh.onrender.com)
Aircraft, ships, satellites, and events streamed onto a 3D globe, plus an investigation workspace that links findings to source evidence.
<br /><sub>React · CesiumJS · Node.js · TypeScript · WebSocket</sub>

**[Boundless](https://github.com/AtfastrSlushyMaker/boundless)**
Local-first AI role-playing game with persistent world state, campaign branching, and generated character portraits.
<br /><sub>Next.js · FastAPI · PostgreSQL · pgvector · Ollama · ComfyUI</sub>

**[The 12th Player](https://github.com/AtfastrSlushyMaker/the-12th-player)** · [Live demo](https://the-12th-player-app.onrender.com)
ML-powered football analytics: Premier League standings and match predictions, tactical styles, and talent scouting across Europe's top 5 leagues.
<br /><sub>Python · Machine learning · TypeScript</sub>
